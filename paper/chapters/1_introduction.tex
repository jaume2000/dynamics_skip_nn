Plain deep stacks such as VGG~\citep{simonyan2015deepconvolutionalnetworkslargescale}
are hard to train as depth grows, partly because gradients vanish or explode through
many layers~\citep{vanishingGradient,glorot2010understanding}.
Residual connections~\citep{he2016resnet} made very deep networks trainable by
letting each block add a correction to its input, $x\mapsto x+f(x)$, which also
yields markedly smoother loss landscapes~\citep{li2018visualizinglosslandscapeneural}.
Because every block writes into the same representation, the stack can be read as a
single state that moves through feature space, and the update has the algebraic form
of one explicit Euler step of an
ODE~\citep{e2017proposal,haber2017stable,lu2018beyond}.
That reading inspired Neural ODEs~\citep{chen2019neuralordinarydifferentialequations},
but whether a \emph{trained} residual network behaves as an integrator is
contested: the analogy can be purely syntactic~\citep{queiruga2020continuousindepthneuralnetworks},
and a stack is guaranteed to approach an ODE only if its blocks vary smoothly in
depth~\citep{sander2022residualneuralnetworksdiscretize}.

Two questions follow, and current tools answer neither well.
The first is geometric: a stage of nine blocks yields nine states, too few to tell
a smooth flow from a sequence of unrelated jumps.
The second is about parameters: if each block were one step of a common flow,
independent weights per block would be largely redundant.
Indeed, a ConvNeXt-T whose nine stage-3 blocks share a single set of weights reaches
$80.36\%$ ImageNet top-1, $0.61$ points below the untied model with $33\%$ fewer
parameters (\cref{sec:weight_tied}).

We address both with one inference-time probe.
We read each block as a local field integrated over one unit of depth and refine it:
apply it $R$ times with step $\Delta t{=}1/R$, so that the stage horizon $T$ is
conserved, without any fine-tuning.
On ConvNeXt, Swin and ResNet the refined stages converge to a continuous limit that
costs less than one top-1 point, whereas changing $T$ collapses every network
(\cref{sec:indefinite_looping}).
We do not propose refinement as a way to build deeper models; we use it because it
turns each stage into a trajectory with hundreds of states per block, on which
velocity, angular velocity, acceleration and curvature can be measured.

These trajectories separate two regimes behind the same algebra (\cref{fig:teaser}).
The weight-tied stage is an autonomous flow $\dot x=f(x)$: it first searches for a
heading, then expands along it and finally refines at low speed
(\cref{sec:geometrical_analysis}).
The untied stage is a switched flow $\dot x=f_{\lfloor t\rfloor}(x)$: nine shallow
arcs joined by turns of about $80^\circ$ at every block boundary.
Measured along the path, almost half of the untied motion is cancelled by later blocks,
and nearly half of all sign reversals fall exactly on block boundaries, against
almost none for the shared field; a frozen decoder can also read the shared state
much earlier in the stage (\cref{sec:overparametrized_undoing}).
Much of the untied capacity in depth is thus spent undoing earlier blocks, which is
why a single shared block recovers almost all of its accuracy.

Our contributions are:
\begin{itemize}
    \item \textbf{Refinement at fixed horizon} as a training-free probe of residual
    stages, with a solver-independent continuous limit that stays usable by the
    downstream network on ConvNeXt, Swin and ResNet
    (\cref{sec:indefinite_looping}).
    \item \textbf{Autonomous versus switched transport}: a weight-tied stage as a
    controlled autonomous counterpart of the standard stack, close in accuracy and
    clearly different in dynamics (\cref{sec:weight_tied,sec:geometrical_analysis}).
    \item \textbf{A kinematic analysis} of feature trajectories (speed, angular
    velocity, tangential and normal acceleration, curvature), after excluding massive
    activations that otherwise dominate the statistics
    (\cref{sec:geometrical_analysis}).
    \item \textbf{A measurement of depth redundancy}: cancelled motion, sign reversals
    at block boundaries, and prefix decoding with the frozen downstream network
    (\cref{sec:overparametrized_undoing}).
\end{itemize}
