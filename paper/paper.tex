\begin{abstract}
Residual blocks compute $x+f(x)$, the form of one explicit Euler step.
We refine trained residual stages at inference, applying each block $R$ times with
step $1/R$ so that the integration horizon is kept, and use the refined path as a
probe that needs no retraining.
Convergence is not the finding, since any Lipschitz residual field has a continuous
limit; what matters is what the limit keeps and how the path is organised.
On ConvNeXt, Swin and ResNet the limit costs less than one ImageNet top-1 point,
whereas changing the horizon collapses every network.
Comparing ConvNeXt-T with a variant whose nine stage-3 blocks share one set of weights
separates an autonomous flow, the shared block, from a switched flow, the independent
blocks, whose heading turns by about $80^\circ$ at every block boundary.
Basis-independent statistics of the block increments show that the independent blocks
write in nearly orthogonal directions that later blocks do not erase: consecutive
increments have cosine $0.17$, against $0.00$ for random blocks of matched strength,
and the stage advances as a staircase with straightness $0.50$, against $0.78$ for the
shared flow and $0.33$ for random blocks.
The shared stage reaches $80.34\%$ top-1 against $80.96\%$ with $33\%$ fewer
parameters, and a frozen decoder can read its features earlier in the stage.
Why one coherent field nearly matches nine independent ones remains open.
Code is available at \url{https://github.com/jaume2000/dynamics_skip_nn}.
\end{abstract}
