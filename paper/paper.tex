\begin{abstract}
Residual blocks compute $x+f(x)$, the form of one explicit Euler step, yet whether
trained residual networks behave as discretised flows remains debated.
We refine residual stages at inference---applying each block $R$ times with step
$1/R$ so that the integration horizon is conserved---without any retraining.
On ConvNeXt, Swin and ResNet the refined stages converge to a continuous limit that
costs less than one ImageNet top-1 point, whereas changing the horizon collapses
every network.
Refinement turns each stage into a high-resolution trajectory on which we measure
speed, angular velocity, acceleration and curvature.
Comparing a standard ConvNeXt-T with a variant whose nine stage-3 blocks share a
single set of weights reveals two regimes behind the same algebra.
The shared block is an autonomous flow that searches for a heading, expands along it
and refines.
The independent blocks form a switched flow: shallow arcs joined by turns of about
$80^\circ$ at every block boundary, where almost half of the motion is undone by
later blocks.
This redundancy explains why the shared stage loses only $0.6$ top-1 points with
$33\%$ fewer parameters, and suggests that residual depth can do more with fewer,
better-used parameters.
Code is available at \url{https://github.com/jaume2000/dynamics_skip_nn}.
\end{abstract}
